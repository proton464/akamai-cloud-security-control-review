# Cloud Security Control Review Case Study (IAM, Logging, Encryption, Vulnerability Management)

**Portfolio Project** | Demonstrates architecture and technical documentation review, control assessment against key cloud security domains, gap analysis, and prioritized remediation recommendations aligned to SOC 2 and ISO 27001.

## One-Sentence Elevator Pitch
A focused case study that reviews a sample cloud architecture against key security controls, documents gaps, and produces remediation recommendations aligned to common frameworks.

## Business / Security Outcome
Provides engineering teams with clear, prioritized gap remediation guidance and gives compliance stakeholders an evidence-based view of control design effectiveness.

## Tech Stack
- Draw.io / diagrams.net — architecture and data-flow diagrams
- Markdown + GitHub — case study narrative
- Microsoft Word or Google Docs — polished narrative (optional)
- Free CIS Benchmarks or public cloud security guidance as reference
- Snagit — annotated diagram screenshots

## Key Features / Deliverables
- [ ] Architecture and data-flow diagram of a sample multi-tier cloud application
- [ ] Control review covering IAM, encryption in transit/at rest, logging/monitoring, and vulnerability management
- [ ] Gap analysis mapped to SOC 2 / ISO 27001 / NIST language
- [ ] Prioritized remediation recommendations with effort estimates
- [ ] Evidence checklist for what an auditor would request
